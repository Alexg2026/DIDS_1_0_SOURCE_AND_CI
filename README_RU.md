# DIDS 1.0 — автоматизация «ОСТРОВА МЕЧТЫ»

Это **готовый локальный конвейер** для существующей V34, не новая версия игрового движка. Все игровые файлы V34 включены в `game/legacy_v34/`.

## Быстрый запуск

Нужен Python 3.10+; Node.js 22 рекомендуется для проверки синтаксиса JavaScript. Сторонние Python-пакеты не нужны.

```bash
python -m unittest discover -s tests -v
python scripts/dids.py audit
python scripts/dids.py build
```

Результат: `reports/qa.json`, `dist/OSTROV_MECHTY_V34_DIDS.zip`, `DIDS_MANIFEST.json` внутри архива. Игру можно открыть из `game/legacy_v34/ОСТРОВ_МЕЧТЫ_V34_ИГРАТЬ.html`.

## GitHub

1. Создайте **свой** репозиторий и загрузите туда содержимое этой папки (не сам ZIP).
2. Сделайте push в `main` или `develop`: GitHub Actions автоматически запускает тесты, аудит и сборку; архив доступен в разделе Actions → Artifacts.
3. Для ручного кандидата: Actions → **DIDS Manual Candidate** → Run workflow → `APPROVED`. Это лишь создаёт артефакт кандидата, **не публикует релиз**.

## Что пока не автоматизировано

Изменение геймплея, создание новых моделей, реальное прохождение в браузере, замеры FPS и художественное утверждение. Вся графика V34 — прототипная. Центральное питание по канону изначально выключено. Режим полуавтоматический: человек принимает ключевые решения.

## Безопасность

Workflow использует `contents: read`, не содержит секретов и не публикует релизы. Перед выкладыванием в публичный репозиторий проверьте права на все включённые изображения и исходные файлы.
