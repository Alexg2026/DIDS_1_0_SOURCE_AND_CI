# DIDS 1.0 — архитектура

- `game/legacy_v34/` — **неизменённый** исходный прототип V34, включая 50 CCTV WebP, HTML и JS. Пока это монолитная версия игры; модульный рефакторинг — отдельный этап, не притворяемся, что он уже сделан.
- `config/project.json` — конфигурация канона, ассетов и сборки.
- `scripts/dids.py` — офлайн аудит, проверка размеров WebP и JS-синтаксиса, воспроизводимая ZIP-сборка, SHA-256 manifest.
- `tests/` — Python unittest без внешних зависимостей.
- `.github/workflows/ci.yml` — проверки на push/PR и артефакт CI.
- `.github/workflows/release.yml` — ручное подтверждение `APPROVED` для кандидата; **не публикует релиз автоматически**.

## Критерии готовности

Сборка запрещена при отсутствии входных файлов, нехватке CCTV-состояний, неправильных размерах WebP, нарушении базового канона питания или синтаксической ошибке JS (если Node.js установлен). Система **не** доказывает, что игровой процесс корректен в браузере, не замеряет FPS и не утверждает финальное качество арта.
