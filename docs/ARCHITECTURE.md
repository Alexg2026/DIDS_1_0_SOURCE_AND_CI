# DIDS 1.1 — архитектура

Модули регистрируют фабрики и функции в `window.DIDS`. IIFE изолируют локальные переменные; порядок подключения задан HTML. Формат сохраняет classic scripts без сборщика. Чистая логика тестируется в Node VM без DOM.

| Файл | Ответственность и зависимости |
|---|---|
| `modules/config.js` | Размеры мира, длительность ночи, названия и пути CCTV |
| `modules/state.js` | Новое состояние ночи; независимые Set, AI и маршруты при reset |
| `modules/world.js` | Карта, предметы, столкновения, BFS и видимость; getter состояния двери |
| `modules/ai.js` | Патрули, обнаружение, преследование и атаки; world, keys, getter состояния и callbacks событий |
| `modules/camera.js` | Выбор CCTV-состояния по переданному состоянию и миру |
| `modules/rendering.js` | Canvas-мир, спрайты, миникарта и выбор 3D-рендера через getter |
| `modules/metrics.js` | Ограниченный кольцевой буфер интервалов кадра и CPU wall time, статистика и reset |
| `renderer3d.js` | WebGL-геометрия; карта, предметы и клавиши передаются явно |
| `game.js` | Координация, DOM/HUD, ввод, инвентарь, питание, симуляция и requestAnimationFrame |

World/AI/state/camera/metrics не обращаются к DOM. Фабрики получают изменяемые зависимости явно. Ввод, HUD и питание остаются в координаторе; публичные тестовые hooks `__V31_TEST__` и `__V32_TEST__` сохранены.

`__DIDS_PERF__.reset()` очищает окно измерения; `snapshot()` возвращает статистику и фактически выбранный рендерер. Буфер ограничен последними 600 кадрами, без роста памяти в течение ночи.

## Конвейер и проверки

`config/project.json` задаёт версию, канон и ассеты. `scripts/dids.py` проверяет вложенные JS, размеры и количество CCTV, собирает детерминированный ZIP с SHA-256-манифестом. Python-часть использует стандартную библиотеку.

`tests/test_pipeline.py` проверяет сборочные инварианты. `tests/modules.test.cjs` проверяет изоляцию состояния, маршруты, столкновения, обнаружение/атаку AI, камеры и статистику. Сохранён legacy-скрипт с 13 игровыми проверками.

Playwright запускает production HTML через HTTP в двух проектах: WebGL и принудительный fallback Canvas 2D. Успешный fallback не засчитывается за WebGL. Проверяются клавиатура и DOM; hooks ускоряют установку позиции и времени. Отчёты не коммитятся: CI публикует JSON/Markdown, HTML, screenshots и traces как артефакты.

Performance-сценарий и ограничения измерений описаны в README. Бюджет обнаруживает крупные CPU-регрессии; для стабильного сравнения FPS нужен фиксированный runner и baseline. Согласованных эталонных кадров пока нет.
